# รันทั้งระบบบน Cloudflare Workers + D1 + R2 + Access

เจ้าของต้องการระบบออนไลน์ตลอด 24 ชม. โดยไม่ต้องดูแลเซิร์ฟเวอร์และไม่มีค่าใช้จ่ายรายเดือน จึงเลือก Cloudflare Workers (free tier) พร้อม D1 เป็นฐานข้อมูล R2 เก็บภาพสลิป และ Cloudflare Access เป็นประตูเข้าเดียวของเจ้าของ แทนการเช่า VPS และเขียนระบบล็อกอินเอง

## Considered Options

- VPS/Docker — คุมทุกอย่างได้เอง แต่ต้องจ่ายรายเดือน อัปเดต และดูแลเครื่อง
- เครื่องที่บ้าน — ฟรีแต่ไม่ออนไลน์ต่อเนื่อง รับ LINE webhook ไม่ได้

## Consequences

- Lock-in กับ bindings ของ Cloudflare (D1/R2/Access) การย้ายแพลตฟอร์มภายหลังมีต้นทุนสูง
- อนาคตถ้าต้องการงานตามกำหนดเวลา เช่น reminder ต้องเพิ่ม Cron Triggers ของ Workers (MVP ไม่มี cron ใดๆ โดยตั้งใจ)
