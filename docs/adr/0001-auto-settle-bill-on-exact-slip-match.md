# ปิดบิลอัตโนมัติเมื่อสลิปผ่าน EasySlip และยอดตรง

เพื่อให้เจ้าของไม่ต้องตรวจสลิปทีละใบทุกต้นเดือน เราตัดสินใจให้ระบบปิดบิลเองทันทีเมื่อสลิปผ่านการตรวจของ EasySlip และยอดตรงกับยอดรวมทั้งสิ้นของบิลที่ยังไม่จ่ายล่าสุดของห้องผู้ส่ง ส่วนสลิปที่ยอดไม่ตรงหรือตรวจไม่ผ่านจะเข้าคิวรอตรวจให้คนตัดสินเสมอ และสลิปหนึ่งใบใช้ปิดบิลได้ไม่เกินหนึ่งใบ

## Consequences

- ความเชื่อใจฝากไว้กับ EasySlip ร่วมกับกติกายอดตรงเป๊ะ ถ้าสลิปปลอมหลุดรอดการตรวจและยอดบังเอิญตรง ระบบจะปิดบิลผิด ยอมรับความเสี่ยงนี้เพราะผู้ใช้มีเจ้าของคนเดียวและคิวรอตรวจคอยรองรับกรณีผิดปกติอยู่แล้ว
- การปิดบิลอัตโนมัติและการยืนยันด้วยมือต้องให้ผลเหมือนกันทุกประการ (สถานะ วันที่ ช่องทาง ข้อความยืนยันกลับผู้เช่า)
