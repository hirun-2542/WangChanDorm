# Spec: ส่งออกรายการบิลเป็นไฟล์ Excel

## Problem Statement

เจ้าของหอดูบิลได้ครั้งละหนึ่งเดือนบนหน้าจอเท่านั้น เวลาจะทำบัญชี สรุปรายรับให้คนในบ้าน หรือเตรียมตัวเลขยื่นภาษี ต้องเปิดทีละเดือนแล้วคัดลอกตัวเลขออกมาเอง ซึ่งช้าและพิมพ์ผิดได้ง่าย ระบบยังไม่มีทางเอาข้อมูลบิลออกไปใช้ในโปรแกรมตารางคำนวณเลย พอจะดูว่าห้องหนึ่งจ่ายอะไรไปบ้างตลอดหลายเดือน หรือค่าใช้จ่ายเพิ่มเติมตัวไหนเก็บไปเท่าไร ก็ต้องกดเข้าออกบิลทีละใบ

## Solution

เพิ่มปุ่ม **"ส่งออก Excel"** ที่หัวหน้ารายการบิล กดแล้วมีหน้าต่างให้เลือกช่วงเดือน ("ตั้งแต่" – "ถึง") พร้อมปุ่มลัด "ปีนี้" กับ "12 เดือนล่าสุด" จากนั้นระบบดาวน์โหลดไฟล์ `.xlsx` ให้ทันที

- **หนึ่งชีตต่อหนึ่งห้องพัก** แต่ละแถวคือบิลหนึ่งเดือนของห้องนั้น เรียงจากเดือนเก่าไปใหม่ ห้องที่ไม่มีบิลเลยในช่วงที่เลือกจะไม่มีชีต
- คอลัมน์เป็นข้อมูลชุดเดียวกับตารางบนจอ ส่วน **ค่าใช้จ่ายเพิ่มเติมแยกเป็นคอลัมน์ละรายการตามชื่อ** และทุกชีตใช้คอลัมน์ชุดเดียวกัน จึงเทียบข้ามห้องได้ตรงตำแหน่ง
- รอบบิลเก็บเป็น **วันที่จริงของ Excel** แสดงแบบไทย พ.ศ. (เช่น "ก.ย. 2569") จึงเรียงและกรองตามช่วงได้
- ไฟล์มี **ทุกบิลในช่วงเสมอ** ไม่ขึ้นกับตัวกรองสถานะ ห้อง หรือคำค้นที่ค้างไว้บนจอ ถ้าต้องการกรองต่อ ให้ใช้คอลัมน์ "สถานะ" ใน Excel
- ไม่มีแถวรวมและไม่มีชีตภาพรวม เพื่อให้ข้อมูลเป็นตารางล้วน sort/filter/pivot ต่อได้โดยไม่มีแถวพิเศษมาปน

## User Stories

1. ในฐานะเจ้าของ ฉันต้องการปุ่มส่งออกบิลที่หน้ารายการบิล เพื่อเอาข้อมูลไปใช้ต่อโดยไม่ต้องคัดลอกทีละเดือน
2. ในฐานะเจ้าของ ฉันต้องการได้ไฟล์ `.xlsx` จริง เพื่อเปิดใน Excel หรือ Google Sheets ได้ทันที ภาษาไทยไม่เพี้ยน และตัวเลขเป็นตัวเลขจริงที่คำนวณต่อได้
3. ในฐานะเจ้าของ ฉันต้องการเลือกเดือนเริ่มและเดือนสุดท้ายเอง เพื่อส่งออกตามรอบที่ต้องการ เช่น ไตรมาส ครึ่งปี หรือทั้งปี
4. ในฐานะเจ้าของ ฉันต้องการให้หน้าต่างเลือกช่วงตั้งค่าเริ่มต้นเป็นเดือนที่กำลังดูอยู่ เพื่อส่งออกเดือนเดียวได้ด้วยการกดยืนยันครั้งเดียว
5. ในฐานะเจ้าของ ฉันต้องการปุ่มลัด "ปีนี้" เพื่อเตรียมตัวเลขทั้งปีภาษีได้ในคลิกเดียว
6. ในฐานะเจ้าของ ฉันต้องการปุ่มลัด "12 เดือนล่าสุด" เพื่อดูภาพย้อนหลังหนึ่งปีโดยไม่ต้องนับเดือนเอง
7. ในฐานะเจ้าของ ฉันต้องการให้ตัวเลือกเดือนมีเฉพาะเดือนที่มีบิลจริง เพื่อไม่เลือกช่วงที่ว่างเปล่าโดยไม่รู้ตัว
8. ในฐานะเจ้าของ ฉันต้องการให้ระบบเตือนเมื่อเลือกเดือนเริ่มหลังเดือนสุดท้าย และไม่ยอมให้ดาวน์โหลด เพื่อไม่ได้ไฟล์ที่ผิดโดยไม่รู้ตัว
9. ในฐานะเจ้าของ ฉันต้องการเห็นข้อความชัดเจนเมื่อยังไม่มีบิลให้ส่งออกเลย เพื่อรู้ว่าไม่ใช่ปุ่มพัง
10. ในฐานะเจ้าของ ฉันต้องการให้แต่ละห้องพักอยู่ชีตของตัวเอง ตั้งชื่อตามเลขห้อง เพื่อเปิดดูประวัติของห้องใดห้องหนึ่งได้ทันที
11. ในฐานะเจ้าของ ฉันต้องการให้ชีตเรียงตามเลขห้องแบบเดียวกับบนจอ (A9 มาก่อน A10) เพื่อหาห้องเจอง่าย
12. ในฐานะเจ้าของ ฉันต้องการให้แถวในชีตเรียงจากเดือนเก่าไปใหม่ เพื่ออ่านประวัติของห้องตามลำดับเวลา
13. ในฐานะเจ้าของ ฉันไม่ต้องการชีตว่างของห้องที่ไม่มีบิลในช่วงนั้น เพื่อไม่ต้องไล่ข้ามแท็บที่ไม่มีข้อมูล
14. ในฐานะเจ้าของ ฉันต้องการเห็นชื่อผู้เช่าในแต่ละแถว เพื่อแยกออกว่าเดือนไหนเป็นของผู้เช่าคนไหน ในกรณีที่ห้องเปลี่ยนผู้เช่าระหว่างช่วง
15. ในฐานะเจ้าของ ฉันต้องการเห็นค่าห้อง ค่าน้ำ ค่าไฟ และยอดรวมของแต่ละบิล เพื่อตรวจกับบิลที่ส่งให้ผู้เช่าได้
16. ในฐานะเจ้าของ ฉันต้องการเห็นหน่วยน้ำและหน่วยไฟที่ใช้ เพื่อดูแนวโน้มการใช้ของแต่ละห้อง
17. ในฐานะเจ้าของ ฉันต้องการให้ห้องที่ค่าไฟแบบเหมาจ่ายยังแสดงหน่วยไฟที่คำนวณจากการอ่านมิเตอร์ เหมือนบนจอ เพื่อให้ตัวเลขในไฟล์ตรงกับที่เห็นในแอป
18. ในฐานะเจ้าของ ฉันต้องการให้ค่าใช้จ่ายเพิ่มเติมแต่ละรายการมีคอลัมน์ของตัวเองตามชื่อ เพื่อรวมยอดของรายการเดียวกัน (เช่น ค่าอินเทอร์เน็ต) ได้ใน Excel
19. ในฐานะเจ้าของ ฉันต้องการให้ทุกชีตมีคอลัมน์ชุดเดียวกันในตำแหน่งเดียวกัน เพื่อคัดลอกหรืออ้างอิงสูตรข้ามชีตได้
20. ในฐานะเจ้าของ ฉันต้องการให้ช่องค่าใช้จ่ายเพิ่มเติมเว้นว่างเมื่อบิลนั้นไม่มีรายการนั้น แทนที่จะใส่ 0 เพื่อแยก "ไม่มีรายการนี้" ออกจาก "มีแต่ยอด 0"
21. ในฐานะเจ้าของ ฉันต้องการให้รายการชื่อซ้ำกันในบิลเดียวรวมยอดกันในคอลัมน์เดียว และชื่อที่ต่างกันแค่ช่องว่างหัวท้ายถือเป็นรายการเดียวกัน เพื่อไม่ให้คอลัมน์แตกโดยไม่จำเป็น
22. ในฐานะเจ้าของ ฉันต้องการเห็นสถานะ "จ่ายแล้ว" / "ยังไม่จ่าย" ของแต่ละบิล เพื่อกรองหาห้องที่ค้างชำระใน Excel
23. ในฐานะเจ้าของ ฉันต้องการให้รอบบิลเป็นวันที่ที่แสดงแบบไทย พ.ศ. เพื่ออ่านง่ายและยังเรียงหรือกรองตามช่วงเวลาได้
24. ในฐานะเจ้าของ ฉันต้องการให้ยอดเงินแสดงมีตัวคั่นหลักพัน เพื่ออ่านยอดได้เร็ว
25. ในฐานะเจ้าของ ฉันต้องการให้แถวหัวตารางตรึงไว้ตอนเลื่อน และคอลัมน์กว้างพอสำหรับข้อความไทย เพื่อไม่ต้องจัดหน้าตาไฟล์เองทุกครั้ง
26. ในฐานะเจ้าของ ฉันต้องการให้ชื่อไฟล์บอกช่วงเดือนเป็นภาษาไทย (เช่น "บิล กันยายน 2569.xlsx" หรือ "บิล มกราคม 2569 - กันยายน 2569.xlsx") เพื่อหาไฟล์เจอในเครื่องภายหลัง
27. ในฐานะเจ้าของ ฉันต้องการให้ไฟล์มีทุกบิลในช่วงเสมอ แม้บนจอจะกรองสถานะหรือห้องค้างไว้ เพื่อไม่ได้ไฟล์ขาดโดยไม่รู้ตัว
28. ในฐานะเจ้าของ ฉันต้องการเห็นข้อความยืนยันหลังดาวน์โหลดว่าส่งออกกี่บิลกี่ห้อง เพื่อรู้ว่าไฟล์ครบตามที่คาด
29. ในฐานะเจ้าของ ฉันต้องการให้ปุ่มดาวน์โหลดแสดงว่ากำลังสร้างไฟล์ และกดซ้ำไม่ได้ระหว่างนั้น เพื่อไม่ได้ไฟล์ซ้ำหลายไฟล์
30. ในฐานะเจ้าของ ฉันต้องการเห็นข้อความผิดพลาดในหน้าต่างเดิมเมื่อส่งออกไม่สำเร็จ โดยที่ช่วงที่เลือกไว้ยังอยู่ เพื่อกดลองใหม่ได้ทันที
31. ในฐานะเจ้าของที่ใช้มือถือ ฉันต้องการปุ่มส่งออกแบบไอคอนที่ไม่เบียดหัวหน้า และหน้าต่างเลือกช่วงที่ใช้บนจอเล็กได้ เพื่อส่งออกได้แม้ไม่ได้อยู่หน้าคอม
32. ในฐานะสมาชิกในครอบครัวที่ช่วยดูแลหอ ฉันต้องการส่งออกได้เหมือนเจ้าของ เพราะฉันเห็นและแก้บิลชุดเดียวกันอยู่แล้ว
33. ในฐานะเจ้าของ ฉันต้องการให้ไฟล์มีเฉพาะบิลของหอฉัน ไม่ปนข้อมูลของครอบครัวอื่นที่ใช้ระบบเดียวกัน
34. ในฐานะเจ้าของ ฉันต้องการให้การเพิ่มปุ่มนี้ไม่ทำให้แอปโหลดช้าลงสำหรับการใช้งานปกติ เพราะส่งออกนาน ๆ ครั้ง แต่เปิดหน้าบิลทุกวัน
35. ในฐานะเจ้าของ ฉันต้องการให้ปุ่มส่งออกกดได้เสมอไม่ว่าจะดูเดือนไหนอยู่ เพราะช่วงที่ส่งออกเลือกแยกจากเดือนบนจอ

## Implementation Decisions

### ขอบเขตข้อมูลและ API

- เพิ่ม endpoint อ่านอย่างเดียว **`GET /api/bills/export?from=YYYY-MM&to=YYYY-MM`** ตอบ `{ ok: true, from, to, bills: Bill[] }` รูปแบบบิลเหมือน `GET /api/bills?period=` ทุกฟิลด์ รวมค่าใช้จ่ายเพิ่มเติม (`charges`) ที่เรียงตามลำดับในบิล เรียงผลตามรอบบิล (เก่า → ใหม่) แล้วตามเลขห้อง (สั้นก่อนยาว แล้วตามตัวอักษร) ครอบทั้งสองปลาย
- การตรวจค่า: `from` หรือ `to` ผิดรูปแบบหรือไม่มี → 400 `VALIDATION` ข้อความ "เดือนต้องอยู่ในรูปแบบ YYYY-MM" ระบุ `field` เป็นพารามิเตอร์ที่ผิด · `from` หลัง `to` → 400 `VALIDATION` "เดือนเริ่มต้องไม่เกินเดือนสุดท้าย" `field: "from"` · ช่วงที่ไม่มีบิลตอบ `bills: []` ไม่ใช่ error · ล้มเหลวภายใน → 500 `INTERNAL` "โหลดข้อมูลบิลไม่สำเร็จ"
- endpoint นี้แยกข้อมูลตามครอบครัวเหมือน `/api/bills/*` ทุกตัว และไม่ตรวจบทบาท เพราะสมาชิกเห็นข้อมูลชุดเดียวกันอยู่แล้ว ไม่จำกัดความยาวช่วง เพราะหอหนึ่งมีบิลไม่เกินหลักร้อยต่อปี
- ตัวโหลดบิลรายเดือนที่มีอยู่ถูกขยายให้รับช่วง `from..to` แทนเดือนเดียว ผู้เรียกเดิม (รายการบิล สร้างบิล ส่งบิลทั้งหมด) ส่งเดือนเดียวกันทั้งสองปลาย จึงได้ผลเท่าเดิมทุกประการ ไม่มีโค้ดโหลดชุดที่สองแยกออกมา
- ไม่มีการเปลี่ยน schema และไม่มี migration

### สร้างไฟล์ในเบราว์เซอร์

- สร้างไฟล์ `.xlsx` **ฝั่งเบราว์เซอร์** จากข้อมูลบิลที่ได้จาก endpoint ข้างบน ไม่สร้างใน Worker เพราะ Worker มีขนาดใกล้ขีดจำกัดอยู่แล้ว (pdf-lib + ฟอนต์ไทยสองไฟล์ รวมราว 3 MB) ส่วน asset ฝั่งเว็บไม่มีข้อจำกัดนี้
- ใช้ไลบรารี `write-excel-file` (v4) และ **โหลดแบบ lazy ตอนกดดาวน์โหลดเท่านั้น** ไม่รวมใน bundle หลัก
- แยก **โมดูลจัดรูปข้อมูลล้วน** (ไม่มี React/DOM/ไลบรารี) ที่รับรายการบิลแล้วคืนรายการชีต แต่ละชีตมีชื่อ รายการคอลัมน์ (หัว · ชนิด · ความกว้าง) และแถวของเซลล์ ส่วนที่แปลงเป็นไฟล์จริงเป็นตัวแปลงบาง ๆ ที่จับคู่ชนิดคอลัมน์กับรูปแบบของ Excel เท่านั้น รูปร่างของข้อมูลกลาง:

  ```ts
  type BillsExportColumnKind = "period" | "text" | "money" | "units";
  interface BillsExportColumn { header: string; kind: BillsExportColumnKind; width: number }
  type BillsExportCell = string | number | Date | null; // null = เซลล์ว่าง
  interface BillsExportSheet { name: string; columns: BillsExportColumn[]; rows: BillsExportCell[][] }
  ```

- สูตรหน่วยไฟของบิลเหมาจ่าย (ใช้หน่วยที่บันทึกไว้ ถ้าไม่มีให้คิดจากผลต่างมิเตอร์) ย้ายไปอยู่ในโมดูลสูตรคิดเงินที่ใช้ร่วมกันระหว่าง worker กับหน้าเว็บ หน้ารายการบิลกับไฟล์ส่งออกจึงใช้สูตรเดียวกัน ตัวเลขไม่มีทางไม่ตรงกัน

### รูปแบบไฟล์

- **คอลัมน์ตามลำดับ:** รอบบิล · ผู้เช่า · ค่าห้อง · หน่วยน้ำ · หน่วยไฟ · ค่าน้ำ · ค่าไฟ · [ค่าใช้จ่ายเพิ่มเติม คอลัมน์ละชื่อ] · รวม · สถานะ ไม่มีคอลัมน์ห้องพัก เพราะชีตคือห้องพักอยู่แล้ว
- **คอลัมน์ค่าใช้จ่ายเพิ่มเติม:** รวมชื่อจากทุกบิลในช่วง (ตัดช่องว่างหัวท้าย ข้ามชื่อว่าง) เรียงตามครั้งแรกที่พบ โดยไล่ตามลำดับที่ API ส่งมา ทุกชีตได้ชุดเดียวกัน · ในบิลเดียว ชื่อซ้ำรวมยอดกัน · บิลที่ไม่มีรายการนั้นเว้นช่องว่าง
- **ชีต:** หนึ่งชีตต่อเลขห้องที่มีบิลในช่วง เรียงแบบเดียวกับ API (ความยาวเลขห้อง แล้วตามตัวอักษร) แถวในชีตเรียงรอบบิลเก่า → ใหม่ · ชื่อชีตคือเลขห้อง ปรับให้ถูกกติกาของ Excel: แทน `\ / ? * [ ] :` ด้วย `-` · ตัด `'` หัวท้าย · ยาวไม่เกิน 31 ตัว · ว่างให้ใช้ "ห้อง" · ชื่อซ้ำ (ไม่สนตัวพิมพ์เล็กใหญ่) ต่อท้าย " (2)", " (3)" …
- **เซลล์:** รอบบิลเป็นวันที่วันที่ 1 ของเดือน แสดงด้วยรูปแบบปฏิทินพุทธแบบไทย (เดือนย่อ + ปี พ.ศ.) · เงินและหน่วยเป็นตัวเลขรูปแบบ `#,##0` (ยอดทุกตัวเป็นบาทถ้วน ตั้งแต่เปลี่ยนมาปัดขึ้น) · สถานะเป็นข้อความ "จ่ายแล้ว" / "ยังไม่จ่าย" ตรงกับตัวกรองบนจอ · หัวตารางตัวหนาและตรึงแถวแรก
- **ชื่อไฟล์:** "บิล {เดือน พ.ศ.}.xlsx" เมื่อเป็นเดือนเดียว หรือ "บิล {เดือนเริ่ม} - {เดือนสุดท้าย}.xlsx" ใช้ชื่อเดือนภาษาไทยเต็มแบบเดียวกับตัวเลือกรอบบิลบนจอ

### หน้าจอ

- ปุ่ม "ส่งออก Excel" (ไอคอน download) อยู่ในแถบปุ่มหัวหน้ารายการบิล ต่อจาก "ส่งบิลทาง LINE" ใช้รูปแบบคู่เดียวกัน คือมีข้อความบนจอกว้าง และเป็นไอคอนอย่างเดียวบนมือถือ ปุ่มกดได้เสมอ
- หน้าต่างเลือกช่วงดึงรายการเดือนที่มีบิลใหม่ทุกครั้งที่เปิด เพราะอาจเพิ่งสร้างบิลเดือนใหม่ มีสถานะ "กำลังโหลดรายการเดือน" / "โหลดรายการเดือนไม่สำเร็จ" / "ยังไม่มีบิลให้ส่งออก" · ค่าเริ่มต้นทั้งสองช่องเป็นเดือนบนจอถ้ามีบิล ไม่งั้นเป็นเดือนล่าสุดที่มีบิล · ปุ่มลัดตั้งช่วงเป็นเดือนแรกถึงเดือนสุดท้ายที่มีบิลในกรอบ "ปีนี้" (ปีปฏิทินปัจจุบัน) หรือ "12 เดือนล่าสุด" และซ่อนเมื่อกรอบนั้นไม่มีบิล
- ยืนยันแล้วปุ่มเปลี่ยนเป็น "กำลังสร้างไฟล์" และกดไม่ได้ · สำเร็จ → ปิดหน้าต่าง แสดง toast "ส่งออก N บิล (M ห้อง) แล้ว" · ช่วงนั้นไม่มีบิล (เช่น ถูกลบระหว่างนั้น) → ข้อความ "ไม่มีบิลในช่วงที่เลือก" และไม่สร้างไฟล์ · error → แสดงข้อความจาก API หรือ "ส่งออกไม่สำเร็จ ลองใหม่อีกครั้ง" ในหน้าต่าง ไม่ปิดหน้าต่าง

## Testing Decisions

- เทสต์ที่ดีตรวจพฤติกรรมที่ผู้ใช้หรือผู้เรียกเห็นได้ ไม่ตรวจโครงสร้างภายใน ถ้าเปลี่ยนวิธีเขียนข้างในแต่ผลลัพธ์เหมือนเดิม เทสต์ต้องยังผ่าน
- **Seam 1: HTTP API** (seam เดิมของโปรเจกต์ สเปก MVP กำหนดให้เทสต์ยิง HTTP response) ครอบคลุม:
  - ช่วงหลายเดือนได้เฉพาะบิลในช่วง ครบทั้งสองปลาย เรียงตามเดือน
  - ค่าใช้จ่ายเพิ่มเติมติดมากับบิล
  - `from` หลัง `to`, รูปแบบผิด และพารามิเตอร์หายตอบ 400 พร้อม `field` ที่ถูกต้อง
  - ครอบครัวอื่นได้รายการว่าง
  - เทสต์เดิมของรายการบิลรายเดือนต้องยังผ่าน เป็นหลักฐานว่าการขยายตัวโหลดเป็นช่วงไม่เปลี่ยนพฤติกรรมเดิม
  - ตัวอย่างที่มีอยู่: `describe("family isolation")` และ helper สร้างห้อง/ผู้เช่า/บิลในเทสต์บิล
- **Seam 2: โมดูลจัดรูปข้อมูล** (seam ใหม่ จำเป็นเพราะไฟล์ถูกสร้างในเบราว์เซอร์ ซึ่ง HTTP ไปไม่ถึง) รับ `Bill[]` คืนรายการชีต ครอบคลุม:
  - ลำดับชีตตามเลขห้อง (A9 ก่อน A10)
  - ทุกชีตมีหัวคอลัมน์ชุดเดียวกัน
  - รายการที่ห้องไม่มีเป็น `null` ไม่ใช่ 0
  - ชื่อซ้ำรวมยอด และชื่อที่มีช่องว่างหัวท้ายรวมคอลัมน์เดียวกัน
  - หน่วยไฟของบิลเหมาจ่ายที่ไม่มีหน่วยบันทึก
  - วันที่ของรอบบิลคือวันที่ 1 ของเดือนนั้น
  - การปรับชื่อชีต (อักขระต้องห้าม, ความยาว 31, ชื่อซ้ำ)
  - รายการบิลว่างได้ผลว่าง
  - ตัวอย่างที่มีอยู่: เทสต์โมดูลข้อมูลล้วนฝั่ง client เช่นเทสต์การแจ้งเตือน
- ตัวแปลงเป็นไฟล์ `.xlsx` (ส่วนที่เรียกไลบรารี) **ไม่มีเทสต์ถาวร** เพราะบางจนแทบไม่มีตรรกะ พิสูจน์ครั้งเดียวด้วยของจริงแทน: สร้างไฟล์จากเบราว์เซอร์จริงแล้วเปิดด้วย LibreOffice แบบ headless เพื่อยืนยันว่า
  - รอบบิลแสดงเป็น "ก.ย. 2569" และเดือนไม่เลื่อนเพราะเขตเวลา
  - ชีตและคอลัมน์ครบ
  - ช่องที่ไม่มีรายการว่างจริง

## Out of Scope

- แถวรวมยอดและชีตภาพรวมทุกห้อง
- การใช้ตัวกรองบนจอ (สถานะ ห้อง คำค้น) กับไฟล์
- CSV, PDF หรือรูปแบบไฟล์อื่น
- ข้อมูลที่ไม่อยู่ในตารางบนจอ ได้แก่ เลขมิเตอร์ก่อน/หลัง อัตราต่อหน่วย วันที่ชำระ วิธีชำระ สถานะการส่ง LINE วันที่สร้างบิล และสลิป
- ชีตของห้องที่ไม่มีบิลในช่วง
- การจำกัดสิทธิ์ส่งออกเฉพาะเจ้าของ
- การส่งออกข้อมูลอื่นนอกจากบิล (ผู้เช่า ห้องพัก รายรับบนแดชบอร์ด)
- การนำเข้าไฟล์ Excel กลับเข้าระบบ

## Further Notes

- บิลเก็บเลขห้องและชื่อผู้เช่าไว้ ณ วันสร้างบิล จึงจัดชีตตามเลขห้องที่อยู่บนบิล ไม่ใช่ห้องปัจจุบัน ถ้าเปลี่ยนเลขห้องภายหลัง บิลเก่ากับบิลใหม่จะอยู่คนละชีต ซึ่งตรงกับสิ่งที่พิมพ์อยู่บนบิลจริง
- รูปแบบวันที่ปฏิทินพุทธเป็นของ Excel ต้องตรวจกับ LibreOffice ตอนพิสูจน์ ถ้า LibreOffice แสดงไม่ตรง ให้ลองรูปแบบสำรองที่ใช้ token ปี พ.ศ. ถ้ายังไม่ได้ ให้ใช้รูปแบบของ Excel ต่อและบันทึกข้อจำกัดไว้ เพราะไฟล์นี้ทำมาเพื่อเปิดใน Excel/Google Sheets เป็นหลัก
- ADR ที่เกี่ยวข้อง: การเลือก Cloudflare Workers เป็นแพลตฟอร์มเดียว (0002) เป็นเหตุผลที่สร้างไฟล์ฝั่งเบราว์เซอร์แทนการเพิ่มน้ำหนักให้ Worker
